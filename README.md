# Programming With Python Assignment-DLMDSPWP01



A Python Application For Ideal Function Selection And Mapping With Docker Containerization.

## OVERVIEW
A project of a Python application designed for determination of best-fitting ideal functions for training data, map test points, and the results are visualized in Bokeh.
It works as follows:
Data (train, ideal, and test) is loaded and program then finds which 4 ideal functions which are best fit using training functions (Least Square Criteria- if deviation ≤ max_train_dev × √2) then assign each test point to one of the 4 chosen ideals if it complies with the criteria and then everything stored in SQLite, visualised via bokeh and finally unit tests are carried out

## PROJECT METHODOLOGY

1.	CSV data files are loaded and inserted into SQLite databases 
2.	Best ideal functions are then selected using least-squares minimization
3.	test data points are mapped using the √2 deviation rule
4.	mapping results are then stored in the database
5.	results are visualized with interactive Bokeh plots
6.	Finally unit tests are carried out for validation

## DETAILED CODE EXPLANATION

## config.py

It is a centralized place which contains database connection settings(path for the SQLite database and it determines acceptable limit range for the mappings of testing data to ideal function) 

## exceptions.py
Raised when data and test point mappings fail to be loaded or validated

## database.py

It wraps a sqlite3 connection which provides create/insert/query helpers(load csv to database and fetching data from SQLite database).

## data_handler.py

It handles data initialization, data loading and validation(loads csv and raises dataload error if there is any problem)

## training_data_handler.py

Handles training csv, ideal functions and test csv data and raises errors if there is missing data

## ideal_function_selector.py

It finds/selects the ideal function that minimises the sum of squared deviations (Least-Square)

## test_point_mapper.py

Maps each test data to chosen ideal functions using the following

Criterion : |y_test – y_ideal(x)| ≤ max_train_deviation(chosen ideal) × √2

## visualiser.py

Generates a multi-panel Bokeh layout.

## test_ideal_function_selector.py

Handles test case and do the validation

## main.py

It is entry point of the application.

It provides the following workflow:

Data Load(Calls functions in database.py to read CSV files and load their contents into the SQLite database), Database Paths, Ideal function selection(Invokes find_best_fit in TrainingDataSet to select the ideal function that most closely matches each training data column.), Test data mapped(Calls map_test_points from TestDataSet to associate each test data point with its corresponding ideal function.), Visualisation(Runs visualizer.py to generate plots of the ideal functions and mapped test data points, then saves the output as a standalone HTML file.), Unit tests
